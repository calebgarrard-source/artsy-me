# Artsy Me, concept site

A redesign concept for Artsy Me, the paint-your-own pottery studio in Evans, Georgia.

Static site: `index.html`, `assets/site.css`, `assets/site.js`, fonts and images. No build step. Open `index.html`, or serve the folder with any static server.

Photographs and the brand mark are the studio's own, from its public site. This is a concept preview and is not the studio's live site.
